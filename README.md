# 🥗 Dieta Saudável

> Aplicação web para organização de refeições e metas alimentares diárias.

## 📋 Descrição

App criado para ajudar no acompanhamento de uma dieta saudável, permitindo visualizar as refeições do dia, definir metas calóricas e manter uma alimentação organizada de forma simples e prática.

## ⚙️ O que o app faz

- Organiza refeições e metas diárias
- Exibe plano alimentar de forma clara e visual
- Permite registrar o que foi consumido no dia
- Ajuda a manter consistência na dieta
